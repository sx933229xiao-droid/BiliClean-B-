# v0.1.4 已知问题

本文件记录源码恢复时通过静态审查确认的问题。恢复阶段刻意不修改这些行为；每项修复都应单独提交并配套测试。

| 优先级 | 问题 | 影响 | 建议 |
| --- | --- | --- | --- |
| P0 | 从严格模式切回其他模式时，严格模式写入的低赞设置不会自动撤销 | 用户可能以为已离开严格模式，但仍持续直接过滤低赞评论 | 把模式预设与用户自定义值分离，或保存切换前快照；增加往返切换测试 |
| P0 | 规则动作允许 `collapse` / `blur`，但评论和视频渲染入口最终强制改成 `hide` | 设置页显示的动作与实际行为不一致 | 若坚持“统一静默隐藏”，应从规则模型和 UI 删除无效选项并迁移旧规则 |
| P1 | `allowManualEnableForCurrentVideo=false` 没有持续强制关闭弹幕 | 用户手动重新开启后可能保持开启 | 监听开关变化并区分程序点击与用户点击，防止循环触发 |
| P1 | “恢复本页内容”把元素加入 `revealed` WeakSet；同一元素后续重新扫描仍会跳过 | 恢复后点击重新扫描可能无法再次过滤原元素 | 把临时恢复状态限定到一次扫描周期或提供显式清除方法 |
| P1 | `diagnosticsEnabled` 只保存开关，没有诊断记录实现 | 界面承诺与实际能力不一致 | 实现严格本地、可清除的诊断信息，或暂时移除开关 |
| P1 | `video-title` 规则可选择 `video` scope，但视频页适配器只处理评论 | 用户创建的规则可能永远不命中 | 增加视频页相关推荐/标题适配，或限制设置页可选 scope |
| P2 | DOM 选择器范围较宽，并会遍历开放 Shadow DOM | B 站页面较大时可能有性能风险或误选 | 添加采样性能指标、缩小观察根节点、为不同页面建立选择器夹具测试 |
| P2 | B 站 DOM 结构变化没有自动化浏览器回归 | 线上改版可能导致静默失效 | 建立脱敏 DOM fixture 测试，并在发布前执行真实页面清单 |

## 必须保持的修复约束

- 评论和视频命中后仍应静默隐藏；
- 不在 B 站页面注入原因、占位卡片或恢复按钮；
- 不扩大权限；
- 不引入远程代码或默认上传数据；
- 修改状态结构时必须增加迁移并验证旧 JSON 备份；
- 修复后同步更新弹窗、设置页、安装说明、隐私说明和交接文档。
