# BiliClean

> 一个让哔哩哔哩浏览体验更加干净、可控和可定制的浏览器扩展。
> A browser extension for a cleaner and more customizable Bilibili experience.

BiliClean 是一个面向哔哩哔哩网页版的开源浏览器扩展，通过可配置的内容过滤规则，帮助用户减少不感兴趣、低质量或干扰浏览体验的内容。

项目的目标不是改变哔哩哔哩本身，而是在浏览器端提供一层更加灵活的内容控制能力，让用户能够根据自己的偏好决定看到什么。

---

## ✨ 功能

### 视频过滤

BiliClean 可以自动过滤符合指定条件的视频，目前包括：

* 过滤低播放量视频；
* 过滤过短视频；
* 支持首页视频过滤；
* 支持搜索结果视频过滤；
* 被过滤的视频可以直接从页面布局中移除；
* 尽可能保持过滤后的页面排版自然。

当前默认规则包括：

* 最低播放量：`50,000`
* 最低视频时长：`60 秒`

相关规则可以在扩展设置中调整。

---

### 评论过滤

BiliClean 提供可配置的评论过滤能力，用于减少低质量或不希望看到的评论。

目前支持的规则包括：

* 评论隐藏；
* @ 提及类评论过滤；
* 根据评论长度判断是否保留；
* 根据点赞数判断是否保留；
* 低点赞评论过滤；
* 用户等级相关过滤规则；
* 新评论保护时间；
* 多个弱信号组合判断。

例如，对于带有 `@` 的评论，可以设置：

* 评论文本长度达到指定值时保留；
* 点赞数达到指定值时保留。

这样可以在减少低质量 @ 评论的同时，降低误伤正常长评论或高质量评论的概率。

---

### 弹幕控制

支持对哔哩哔哩播放器中的弹幕进行控制。

BiliClean 的设计方向是减少观看视频过程中不必要的视觉干扰，让视频内容本身成为主要焦点。

---

### 自定义设置

扩展提供独立设置页面，可以根据个人需求调整过滤行为。

部分规则包括：

* 视频最低播放量；
* 视频最低时长；
* 评论过滤方式；
* 低点赞评论规则；
* @ 评论规则；
* 用户等级规则；
* 不同功能模块的独立启用与关闭。

项目仍在持续开发，后续会逐步增加更多可配置规则。

## 🎯 项目目标

BiliClean 希望解决的核心问题是：

**用户应该拥有更多决定自己看到什么内容的权利。**

现代内容平台通常由推荐算法决定用户看到的信息，而用户能够直接控制的内容相对有限。

BiliClean 尝试在浏览器端增加一层用户自己的过滤系统：

```text
Bilibili
    ↓
页面内容
    ↓
BiliClean 规则引擎
    ↓
过滤 / 保留
    ↓
用户最终看到的页面
```

项目重点关注：

* 更高的内容信噪比；
* 更少的视觉干扰；
* 更少的低质量内容；
* 更灵活的用户规则；
* 尽量自然的页面布局；
* 尽可能降低正常内容被误过滤的概率。

## 📦 安装

目前可以通过开发者模式手动安装 BiliClean。

### Chromium 浏览器

适用于：

* Google Chrome
* Microsoft Edge
* Brave
* 以及其他 Chromium 系浏览器

### 安装步骤

1. 下载本项目源代码；
2. 解压到一个固定文件夹；
3. 打开浏览器的扩展管理页面；
4. 开启 **开发者模式（Developer mode）**；
5. 点击 **加载已解压的扩展程序（Load unpacked）**；
6. 选择包含 `manifest.json` 的 BiliClean 文件夹；
7. 安装完成。

Chrome 可以在地址栏进入：

```text
chrome://extensions/
```

Microsoft Edge 可以进入：

```text
edge://extensions/
```

安装完成后即可在浏览器扩展列表中看到 BiliClean。

更加详细的安装说明请参阅：

[安装说明.md](./安装说明.md)

## ⚙️ 项目结构

```text
BiliClean/
├── background/
│   └── service-worker.js
│
├── content/
│   ├── bootstrap.js
│   └── style.css
│
├── icons/
│
├── options/
│   ├── index.html
│   ├── index.css
│   └── index.js
│
├── popup/
│   ├── index.html
│   ├── index.css
│   └── index.js
│
├── manifest.json
├── 安装说明.md
└── 隐私说明.md
```

主要模块：

| 模块              | 作用             |
| --------------- | -------------- |
| `background`    | 扩展后台逻辑与配置管理    |
| `content`       | 页面内容检测、过滤与样式处理 |
| `options`       | 完整设置页面         |
| `popup`         | 浏览器工具栏弹出界面     |
| `icons`         | 扩展图标           |
| `manifest.json` | 浏览器扩展配置        |

如果遇到以下问题：

* 视频没有被正确过滤；
* 评论过滤出现误判；
