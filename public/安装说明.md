# BiliClean v0.1.4 安装说明

## Chrome

1. 解压 `BiliClean-v0.1.4-install.zip`，不要直接在压缩包内运行。
2. 在地址栏打开 `chrome://extensions/`。
3. 打开页面右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择刚刚解压出来、内部直接含有 `manifest.json` 的文件夹。
6. 打开哔哩哔哩视频页、首页或搜索页，点击工具栏中的 BiliClean 图标查看状态。

## Microsoft Edge

1. 解压安装包。
2. 在地址栏打开 `edge://extensions/`。
3. 打开“开发人员模式”。
4. 点击“加载解压缩的扩展”，选择内部直接含有 `manifest.json` 的文件夹。

## 首次使用建议

- 默认使用“标准”模式；视频页会先合批处理首批最多 50 条评论，命中评论直接隐藏，不显示过滤提示。
- 默认关闭弹幕，但允许你在当前视频中手动重新开启；切换到下一视频后会再次关闭。
- 弹窗提供“直接过滤低点赞评论”开关和阈值；新安装默认关闭。
- 含 `@` 的互动评论默认隐藏；只有字数大于 50 且点赞大于 100 时才保留。
- 首页和搜索页默认分别屏蔽播放量低于 5 万或时长短于 60 秒的视频。
- 完整设置页会累计显示已屏蔽评论和视频数量；只记录数量，可随时清零。
- 选择“严格”模式时会自动启用“点赞数 ≤ 1”的直接过滤，并保留 24 小时新评论宽限。
- 在“完整设置 → 关键词规则”中添加个人关键词；评论规则和视频标题规则需要分别创建。
- 如果误伤，可在扩展弹窗中点击“恢复本页内容”，或暂时关闭评论/视频卡片过滤模块。

## 更新或卸载

- 从 v0.1.0–v0.1.3 更新：用 v0.1.4 文件替换原扩展目录后，在扩展管理页点击 BiliClean 卡片中的“重新加载”，并刷新已经打开的 B 站页面。已有规则、名单和低点赞设置会保留；新评论规则、视频阈值与本地数量统计会默认启用。
- 卸载：在扩展管理页点击“移除”。卸载会清除扩展的本地设置。
- 扩展不会接管登录，也不会修改哔哩哔哩账号中的服务器端设置。

## 当前版本范围

v0.1.4 支持：

- `www.bilibili.com/video/*`：首批最多 50 条评论合批过滤、静默隐藏、用户规则、默认关闭弹幕。
- `www.bilibili.com/`：视频标题、UP 主、播放量与时长过滤，命中卡片静默隐藏并由原生网格回流。
- `search.bilibili.com/*`：视频标题、UP 主、播放量与时长过滤，命中结果静默隐藏且不显示扩展提示。

动态页、空间页、本地 AI 分类和图片 OCR 不在本版本范围内。
