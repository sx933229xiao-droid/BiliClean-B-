# BiliClean 隐私说明

版本：v0.1.4  
更新日期：2026-07-27

BiliClean 是本地运行的浏览器扩展。它只在匹配 `*.bilibili.com` 的网页中读取已经显示在页面上的评论、用户公开信息和视频卡片，用于即时决定是否静默隐藏这些页面元素。

## 不收集的内容

- 不读取、保存或上传哔哩哔哩账号密码。
- 不读取、导出或上传 Cookie。
- 不上传评论正文、图片、浏览记录、用户 ID 或设置。
- 不自动点赞、投币、收藏、关注、举报、评论或发送弹幕。
- 不使用远程代码、远程模型、遥测或广告 SDK。

## 本地保存的内容

扩展使用 `chrome.storage.local` 保存：

- 总开关、净化模式、模块开关和阈值。
- 用户创建的关键词规则。
- 用户手动填写的评论用户和 UP 主黑白名单。
- 设置数据结构的版本号。
- 已屏蔽评论和视频的累计数量及统计起始时间。

本地数量统计在 v0.1.4 中默认开启，只保存两个累计数字和统计起始时间，不保存评论正文、视频标题、网址或用户信息。本地诊断信息仍默认关闭。

## 权限用途

- `storage`：在本机保存设置、规则和名单。
- `*://*.bilibili.com/*`：在哔哩哔哩页面中运行内容脚本并修改当前页面展示。

扩展不申请 `<all_urls>`、`tabs`、`cookies`、`webRequest` 或 `unlimitedStorage`。

## 数据控制

用户可以在设置页导出或导入 JSON 备份、单独清零累计统计，也可以使用“恢复默认设置”清除规则、名单与统计。卸载扩展后，Chrome/Edge 会清除扩展的本地存储。

## 说明

本测试版没有服务器端服务，因此不存在把本地内容发送到项目服务器的过程。未来若增加任何云端能力，必须作为独立的明确授权功能重新说明。
